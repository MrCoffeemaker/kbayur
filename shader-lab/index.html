SHADER LAB / NOTES

A layered generative canvas. Add shapes, images, text and procedural patterns, rearrange them, then dial in every layer from the inspector.

Image shaders and blur affect the layers beneath them. The default Liquid Gold artwork is generated live, not a static image.

Save a .shaderlab file to preserve settings. Images are embedded in the file; video clips are session-only and must be reimported. Export PNG for a still, or record a short WebM animation.

Keys: Ctrl/⌘+Z undo, Ctrl/⌘+Shift+Z redo, Space play/pause (outside inputs). Drag an image or video onto the canvas to add it.
